# 0.2 Tauri Desktop Scaffolding

## Context

<context>
This step initializes the Tauri 2.0 desktop application inside the monorepo at `apps/desktop/`. Tauri uses a Rust backend for system-level operations (system tray, notifications, timers, SQLite) and a web frontend (React 19 + Vite + Tailwind CSS 4) for the UI. The desktop app is the primary platform — it runs in the system tray and delivers posture reminders. This step creates the scaffolding only; the actual system tray logic, timer engine, and UI are built in Phase 1.
</context>

## Prerequisites

<prerequisites>
- Step 0.1 (Monorepo Initialization) is complete
- Rust toolchain installed (`rustup` with stable channel, verified with `rustc --version`)
- Tauri CLI installed (`cargo install tauri-cli` or via `npm`)
- System dependencies for Tauri installed (varies by OS — see Tauri docs for WebView2 on Windows, webkit2gtk on Linux)
</prerequisites>

### File Naming Conventions

## Troubleshooting

| Symptom | Likely Cause | Fix |
|---|---|---|
| `tauri dev` fails with "WebView2 not found" (Windows) | Missing WebView2 runtime | Install WebView2 from Microsoft or use Tauri's bootstrapper |
| `tauri dev` fails with "webkit2gtk not found" (Linux) | Missing system dependency | Install `libwebkit2gtk-4.1-dev` via apt |
| Rust compilation errors | Incorrect Tauri plugin versions | Ensure all `tauri-plugin-*` crates match the Tauri 2.0 version |
| Tailwind CSS 4 not working | Using v3 config syntax | Tailwind CSS 4 uses CSS-based config (`@theme`), not `tailwind.config.js` |
| `invoke` not recognized | Missing `@tauri-apps/api` v2 | Install `@tauri-apps/api@^2` (not v1) |
